## 2. 预演分级

分级按"**静态手段能否证明改动正确**"判定，不按改动大小：

| 级别 | 适用范围 | 预演要求 |
| --- | --- | --- |
| A | 含异步/状态机/后台任务/外部 API 接线的改动；**功能改动其单测覆盖靠 mock 顶替真实外部依赖的，自动归 A**；核心链路（每日采集入库 → 榜单计算 → 榜单/关注页展示）一律 A | 强制字面预演：浏览器自动化打真实运行服务，每步按字面跑通；机器产物必须落盘（截图＋result 文件），汇报不算数 |
| B | 纯展示层 SSR/文案/样式（出错最多难看，不产生静默错误数据） | 本地起真实服务截图＋DOM/肉眼核对即收口；步骤卡仍给，免逐步预演流程 |
| C | 纯文档/测试补丁/不影响运行时行为的配置微调（部署、调度、鉴权类配置不算，归 A） | 免预演，统一验证入口跑绿即收口 |

- 判不了级的从紧归 A。
- 无法预演的步骤：显式标注"AI 未预演＋原因"＋替代证据，不许含糊带过。
