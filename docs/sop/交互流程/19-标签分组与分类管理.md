# §19 标签分组与分类管理（T-039 追加，v3.0，2026-08-23 本人拍板口径起草，待文字层确认）

> 需求来源：2026-08-23 本人拍板三条——①数据模型标签↔分类多对多（一标签可属多分类），新表 `tag_category(tag, category)`；②/tags 标签云页改分组展示，底部"未分类"组放无映射标签；③分类管理全做且全部点选式（手机端不用拖拽，复用 T-035 自绘下拉组件形态）：新建、归类（加入/移出）、改名、删除（映射级联删除、标签回落未分类，标签本身与仓上打标记录不动）。
> 组件分档：管理控件全复用既有冻结组件形态（打标输入框/T-035 自绘下拉/chip），免示意图（2026-08-09 分档口径）；开发完以真实页面截图交付走查。

### 19.1 位置与元素
- /tags 总页由平铺标签云改**分组展示**：每个分类一组，组头＝分类名＋组内标签数；分类组按分类名字典序排列；组内标签按使用次数降序（同数按标签名，沿用既有标签云口径）；**底部"未分类"组**放无映射标签。
- 一标签属多分类时在多个组各出现一次（分组语义；不同于 P6"筛选不重复"口径，两者不冲突——§12.2 管 P6 行不重复，本节管 /tags 标签 chip 按组陈列）。
- 管理控件只在 /tags 总页：页头"＋新建分类"；每个标签 chip 旁归类钮；每个分类组头改名钮与删除钮。/tags/<tag> 结果页不变。
- 零分类退化：没有任何分类时页面与平铺标签云现状一致，不渲染分组结构与"未分类"组头。

### 19.2 主路径（全部点选式）
1. **新建分类**：点页头"＋新建分类"→ 展开输入框（打标输入框同款形态：回车提交、Escape 还原、非法红边内联提示）→ 提交后新分类组出现（空组，组头在、组内无标签）。
2. **归类**：点标签 chip 旁归类钮 → 自绘多选下拉列出全部分类（已属分类打勾）→ 点选即切换加入/移出（点一下加入、再点一下移出）；一个标签可勾多个分类。
3. **改名**：点分类组头改名钮 → 输入框改新名提交 → 该分类下全部映射换名；新名与既有分类撞名时合并（重复映射去重），不报错。
4. **删除分类**：点分类组头删除钮 → 即时删除＋toast（无二次确认——只清映射、可逆代价低，与"× 删除标签""取消关注"无确认的既有口径一致）→ 该分类组消失，其下标签回落"未分类"组。
5. 每次管理操作成功后整页刷新，重渲染分组结构。

### 19.3 分支与异常
- 幂等：重复新建同名分类、重复加入同一映射、删除不存在的分类/映射，均幂等返回不报错（对齐既有 /api/tags 口径）。
- 非法输入：分类名/标签去首尾空格后为空或超 20 字符 → 不提交，红边＋内联提示（同打标输入约束）。
- 归类目标校验：标签不存在（tags 去重集合中无）或分类不存在 → 报错不写入。
- 悬空映射：某标签最后一条打标记录被删后其分类映射残留——不显示、不报错，随分类改名/删除自然清理。

### 19.4 服务端口径（钉死）
- 表结构：`tag_category(tag TEXT, category TEXT, PRIMARY KEY(tag, category))` 纯多对多映射；无映射记录的标签＝未分类；打标流程完全不写分类，新标签天然落未分类。
- 空分类表达：新建分类写 `tag=''` 占位行（真实标签最小 1 字符，空串不可能撞真实标签）；分组装配与使用次数统计跳过 `tag=''` 行。
- 装配：以 tags 表去重集合为准 JOIN 映射；悬空映射行不显示（不 fail-loud，无害残留）。
- 删除分类级联边界：只删 tag_category 中该分类全部行（含占位行）；tags 表与仓上打标记录不动；/tags/<tag> 结果页不受影响。
- 不进任何其他链路：榜单、P6 筛选、打标下拉建议（T-035）、AI 范围集，一概不变——分类只是标签页的展示/管理层概念。
