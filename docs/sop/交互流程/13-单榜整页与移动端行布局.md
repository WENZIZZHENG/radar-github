# §13 单榜整页＋移动端行两行布局（T-026 追加，v2.1，2026-08-14 本人拍板）

> 动因：本人手机实测反馈——全量 17 榜 SSR 体积大（/ 640KB、/total 1.7MB，gzip 前）全量加载慢；窄屏榜单行定宽列挤压致项目名不可读。三决策 2026-08-14 本人拍板：①P4 纳入边栏（§12.1 修订）；②移动端两行布局选 B（项目名独占第一行）；③单榜整页选 B（边栏项整页链接）。本人豁免原型直接开发。

### 13.1 单榜整页（P1/P2/P3/P4 榜单四页）
- URL：现有榜单页加 `?board=<榜key>` 查询参数，榜 key＝榜块锚点 id 去 `b-` 前缀（如 `language-java`、`topic-ai`）。P1 `/?board=`（可叠加 `?week=`）；P2 `/quarter?board=`（可叠加 `?quarter=`）；P4 `/total?board=`（无期次）。
- 默认与全量：无 board 参数 → 默认首榜（语言组第一榜 `language-java`）；`board=all` → 全量 17 榜（保留全量入口，边栏顶部"全部"项）；非法 board 值静默降级按默认首榜处理（不报错页）。
- 边栏：各项由页内锚点改为整页链接（`?board=xxx`；P1/P2 携带当前期次参数）；当前榜项高亮由服务端渲染（原 scrollspy 移除）；17 项行数徽标照常全量显示（后端照算各榜行数，仅内容区收窄为单榜）。
- 内容区：元信息行＋当前榜块（主榜行＋（P1/P3）新崛起区＋空态文案），其余榜块不渲染；顶栏期次切换与批量按钮行为不变（批量翻译/推荐语的后端范围口径与页面渲染无关，仍上榜∪关注集）。
- 兼容：旧页内锚点链接 `/#b-xxx` 由前端一行 JS 自动改写跳转 `?board=xxx`。
- 首期降级页（初始总星榜＋倒计时）维持全量现状，不单榜化。
- P5/P6 无 board 概念，不动。

### 13.2 移动端榜单行两行布局（≤640px）
- 布局：第一行＝排名＋项目名（独占整宽，仍 ellipsis 但宽度充足）；第二行＝语言徽标＋本周增星＋总星＋关注星标。
- 纯展示层：不改数据与交互（整行可点/详情面板展开不变）；共用行模板，P1~P6 窄屏同步生效；桌面端形态不变。
