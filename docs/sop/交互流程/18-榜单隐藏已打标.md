# §18 榜单"隐藏已打标"开关（T-038 追加，v3.0，2026-08-23 本人拍板口径起草，待文字层确认）

> 需求来源：2026-08-23 本人拍板——生产实测打标 49 仓/52 次，实际用法是"打标＝已读过"，榜单大量老面孔重复出现；加服务端 URL 参数开关隐藏已打标行，默认关闭（完整榜单是口径基线）。
> 组件分档：开关为页内链接、提示与空态为小字——无新视觉元素，免示意图（2026-08-09 分档口径）；开发完以真实页面截图交付走查。

### 18.1 位置与元素
- 范围：P1/P2/P3/P4 榜单四页（含历史期次与 `?board=` 单榜整页）；P5 标签页、P6 我的关注不设本开关。
- 开关：元信息行下、榜单区上一行——关态显示"隐藏已打标"链接，开态显示"已隐藏 N 个已打标项目 · 显示全部"（N>0 才带计数；N=0 只显示开关互跳文案，不出计数）。
- 空态小字：开启后某榜三区（新崛起区/新项目区/主榜）行全部被隐藏时，该榜块渲染榜头＋一行"本榜 N 个项目均已打标隐藏"，区头与空壳不渲染。

### 18.2 主路径与分支
- 点"隐藏已打标"→ 当前页 URL 追加 `hide_tagged=1` 整页跳转 → 打过标（该仓有任意标签）的行在主榜/新项目区/新崛起区全部不显示；点"显示全部"→ 回到无该参数的完整榜单。
- 状态随 URL 走：可收藏、刷新不丢；开态下点边栏项、期次分段控件，目标链接均携带 `hide_tagged=1`（含历史周 `week=` 与 `board=` 组合），跨期次/跨榜导航不丢开关；关态链接一律不带该参数。
- 非法值静默按关：`hide_tagged` 缺省、空值、非 `1` 取值均按关闭渲染，不报错。
- 首期空态降级不受隐藏影响：降级判定跑在过滤前数据上；降级渲染的总星榜行同样应用过滤。

### 18.3 服务端口径（钉死）
- "已打标"＝该仓在 tags 表存在任意标签（不看标签内容、不看分类）；dead 仓有标签同样隐藏。
- 过滤在展示装配层做（行视图本已注入每仓标签数据）：不动榜单计算口径（出席/排序/Top N/三区互斥），不动 board_cache 结构与内容，部署无需重跑预计算。
- 隐藏计数 N 按被隐藏的行数计（同仓多榜重复出现按行分别计），不按仓去重。
- 榜头数量、区头徽标、边栏徽标保持过滤前完整榜单口径，不随隐藏缩水。
