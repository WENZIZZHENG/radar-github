## 1. 主栈一览
- 前端：Jinja2 服务端渲染 + 少量原生 JS（无前端框架）
- 后端：Python 3.12+ / FastAPI + httpx（async）+ APScheduler（进程内调度）
- 数据库：SQLite（WAL 模式，单文件）
- AI：DeepSeek API（deepseek-chat）
- 部署：云服务器 systemd 托管 uvicorn；Caddy 反代（已有域名，自动 HTTPS + basic auth）

## 2. 数据模型概要
- `repos`：仓库主表（id, full_name, node_id, description_en/zh, language, topics JSON, dead 标记, 入池来源/时间）；中文翻译懒写入本表（node_id＝GraphQL Relay 全局 ID，每日 `nodes(ids:)` 批量采集必需；初版字段清单遗漏，2026-08-09 勘误补入）
- `star_snapshots`：星数快照（repo_id, captured_at, stars），主键 (repo_id, captured_at)，每日每仓库一行
- `follows`：关注（repo_id, created_at）
- `tags`：自定义标签（repo_id, tag）
- `recommendations`：推荐理由（repo_id, dimension[week/quarter/total], period_label, text, readme_sha NULL）；周/季维度按周期重生成、总星维度懒生成＋README 变更（sha 指纹）当日重生（2026-08-11 决策 6 v2，dimension/readme_sha 列由 T-017 幂等迁移补入）
- 榜单**实时 SQL 计算**（两快照差值排序），不做物化表；慢则加缓存（已入想法池候选）
