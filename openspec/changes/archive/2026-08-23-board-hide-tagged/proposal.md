# 提案：榜单"隐藏已打标"过滤

## Why

生产实测：本人已打标 49 仓 / 52 次（24 个标签），实际用法是"打标＝已读过"。后果是每周扫榜时主榜 Top50、新崛起区、新项目区里大量老面孔重复出现，扫读噪音随打标量线性上升——而"已读过"的仓恰恰是本人最不需要再看的信息。

目标：给榜单页一个"隐藏已打标"开关，开启后打过标的行整行不显示，让榜单只剩"没读过的"。

## What Changes

- **榜单四页（P1 本周/P2 历史周/P3 季度/P4 总星）加 URL 参数 `hide_tagged=1`**：服务端过滤，开启时主榜、新崛起区、新项目区中打过标（该仓有任意标签）的行全部不渲染；缺省/其他值＝关闭（完整榜单是口径基线，默认行为不变）。
- **计数提示**：开启时页面给出"已隐藏 N 个已打标项目"一行小字提示（防误以为榜空/数据丢失）；N 按被隐藏的行数计。
- **空态**：开启后某榜三区行全部被隐藏时，该榜块渲染"已全部隐藏"空态小字（榜头保留）；不触发首期降级口径变更。
- **状态随 URL 走**：开关是页内 GET 链接（开/关互跳），开启时边栏项、期次分段控件等页内导航链接携带 `hide_tagged=1`——可收藏、刷新不丢、跨期次/单榜导航不丢。
- **过滤位置**：展示装配层（行视图已注入每仓标签数据，过滤不动榜单计算、不动 board_cache 缓存结构与口径）。
- **不动的部分**：榜单计算口径（出席/排序/Top N/三区互斥）、board_cache、P5 标签页、P6 关注页、打标/关注交互，全部不变。

## Capabilities

### New Capabilities

- `board-hide-tagged`: 榜单页"隐藏已打标"开关的 URL 契约、过滤范围、计数提示与空态行为。

### Modified Capabilities

（无——本变更不改榜单计算与既有页面契约，过滤为新增的可选展示层收窄。）

## Impact

- **代码**：`app/web/routes.py`（三口径路由接 `hide_tagged` 参数、`_boards_context` 行视图过滤与隐藏计数、边栏/分段控件链接透传参数）、`app/web/templates/boards.html` 与 `_board.html`（开关元素、计数提示行、榜块空态小字）。
- **数据**：无迁移；tags 表只读复用。
- **测试**：新增过滤口径测试（开/关、三区、计数、空态、参数透传）；既有榜单页测试不受影响（默认关闭）。
- **外部依赖**：无新增。
- **项目 SOP**：改用户可见页面行为 → OpenSpec change 先行；视觉为既有组件复用（链接开关＋小字提示），免示意图档，开发完以真实页面截图交付本人走查。
