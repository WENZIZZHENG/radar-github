# 设计：榜单"隐藏已打标"过滤

## Context

现状：榜单四页共用 `_boards_context`（routes.py）装配——`compute_boards`/board_cache 产出 `Board`（rows 主榜 / fresh 新项目区 / rising_rows 新崛起区），`_board_view` 把每行装配成行视图（`tags` 字段来自 `_display_maps`，本就注入）；模板 `boards.html`/`_board.html` 三区渲染。P5/P6 与打标 API 与本变更无关。

约束：S 档单人项目；完整榜单是口径基线（默认关闭已拍板）；fail-loud 为既定姿态；不改 board_cache 结构（改了就要重跑预计算，本变更没必要）。

## Goals / Non-Goals

**Goals:**
- 三口径榜单页（含历史期次、单榜整页 `?board=`）支持 `hide_tagged=1`：打过标的行在主榜/新项目区/新崛起区全部不渲染。
- 开启时页面有一行"已隐藏 N 个已打标项目"计数提示；某榜三区全被隐藏时该榜块有空态小字。
- 开关状态在 URL 上：可收藏、刷新不丢、页内导航（边栏项、期次分段控件、开关本身互跳）不丢。

**Non-Goals:**
- 不改榜单计算口径（出席/排序/Top N/三区互斥/降级判定一律不变；隐藏不改变任何一榜的"完整口径"语义）。
- 不改 board_cache 结构与序列化白名单（过滤在展示装配层做，缓存内容不变）。
- P5 标签页、P6 关注页不加此开关；打标/关注交互不变。
- 不做"默认开启"或用户偏好持久化（URL 即状态，已拍板）。

## Decisions

### 决策 1：过滤在展示装配层（`_board_view` 之后/之内），不进 `compute_boards`
行视图已带 `tags: list`（`_display_maps` 注入，routes.py:435 起），过滤＝丢弃 `tags` 非空的行视图。理由：
- 榜单计算与缓存是口径基线，隐藏是纯展示收窄，进计算层会污染口径与缓存语义；
- board_cache 一行不用动，部署无需重跑预计算；
- 历史期次实时算与当前期次缓存两条路径天然一致（过滤发生在两条路径汇合后的装配层）。
备选：在 `compute_boards` 加参数过滤——否决，理由如上。

### 决策 2："已打标"＝该仓有任意标签（tags 表存在该 repo_id 的任意行）
不考虑标签内容、不区分分类。与本人"打标＝已读过"的实际用法一致。dead 仓若打过标同样隐藏（过滤只看 tags，不看 dead）。

### 决策 3：参数解析——仅 `hide_tagged=1` 为开，其余一律关
`hide_tagged` 缺省、空值、非 "1" 值均按关闭处理（静默降级，不 400），与既有 `board` 参数"非法静默降级"风格一致。

### 决策 4：计数 N＝本次渲染被隐藏的行数（按行计，不按仓去重）
同一仓在多榜重复出现时按行分别计入。提示行位置：元信息行下、榜单区上一行小字（如"已隐藏 N 个已打标项目 · 显示全部"链回关态）。N=0 时不渲染提示行（开了开关但本页无已打标行，无噪音）。
备选：按仓去重计数——否决，用户感知对象是"少了多少行"，按行计与视觉一致。

### 决策 5：榜头/区头计数徽标保持过滤前口径
榜头"Top 50"、区头徽标、边栏徽标均显示完整榜单口径数量，不随隐藏缩水——完整榜单是口径基线，隐藏是临时视图；计数提示行已交代隐藏量，两处数字不互相追逐。
备选：徽标显示过滤后数量——否决，会与口径基线混淆（"Top 50"变"Top 43"像数据缺失）。

### 决策 6：页内导航链接透传 `hide_tagged=1`
开关开启时：边栏项链接（`_sidebar_items` base/period_query 之外追加）、期次分段控件（`_switcher`）、开关互跳链接均携带 `hide_tagged=1`；关闭态链接一律不带（URL 保持干净）。榜单四页适用；P5/P6 链接不涉及。

### 决策 7：空态分级
- 某榜三区行全被隐藏：该榜块渲染榜头＋一行小字"本榜 N 个项目均已打标隐藏"，不渲染区头与空壳；
- 首期空态降级判定（三区全空→总星榜降级）不受隐藏影响——判定跑在过滤前的 boards 上，隐藏不触发/不抑制降级；降级渲染的总星榜行同样应用过滤。

## Risks / Trade-offs

- [过滤依赖行视图 `tags` 字段完整性] → `_display_maps` 是既有注入路径（P1~P6 全页面同一份），无新增查询；tags 表 GROUP BY 规模小（生产 52 行），性能无感。
- [隐藏后单榜整页变空] → 决策 7 榜块空态覆盖；不误判首期降级（判定在过滤前）。
- [开关链接参数拼装遗漏] → 透传点集中在 `_sidebar_items`/`_switcher`/开关三处，测试逐一钉死（含历史周 `week=` 与 `board=` 共存组合）。

## Migration Plan

纯代码变更，无迁移、无缓存刷新：部署重启即生效。回滚＝代码回滚重启。
